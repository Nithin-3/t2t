# t2t - Omegle Clone Video Chat App

This app lets you video chat with anyone, similar to Omegle. Instantly connect and start a random video conversation with strangers from anywhere in the world.

**Live Demo:**  
[https://nithin-3.github.com/t2t](https://nithin-3.github.com/t2t)

## Features

- Random video chat with strangers
- Simple and fast connection
- Easy to use interface
- Peer-to-peer video powered by **WebRTC**
- Uses **WebSocket** for real-time signaling and matching users

## Getting Started

Visit the live demo to start chatting:  
[https://nithin-3.github.com/t2t](https://nithin-3.github.com/t2t)

## How It Works

- WebRTC enables direct, secure video and audio streaming between users.
- WebSocket is used for signaling: exchanging connection information and matching users for chat.

## About

Built as an Omegle clone for effortless video chatting.  
No installation or setup required – just visit the site and start talking!
